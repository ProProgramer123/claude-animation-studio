An MCP server for Claude Code

Describe an animation. Six agents make it.

Claude Animation Studio runs inside Claude Code. A hidden director turns your one-line prompt into a full creative brief, then five agents storyboard, design, animate, render and review it, in 2D or 3D. It runs on your Claude Code login, so there's no API key to set up.

How it works

You only ever type the prompt. Everything below happens on its own, and every step's output is saved next to the finished animation so you can see how it was made.

  1. 00

    Director hidden

    Turns your rough prompt into a detailed creative brief: subject, setting, mood, style and key moments.

  2. 01

    Storyboard

    Breaks the brief into scenes and timing.

  3. 02

    Designer

    Decides the characters, colors and objects.

  4. 03

    Animator

    Writes the movement and keyframes.

  5. 04

    Renderer

    Turns the plan into working SVG, canvas or Three.js code.

  6. 05

    Reviewer

    Checks the result and sends fixes back if something looks off.

Before the reviewer looks, the studio opens the animation in a headless browser. Errors, or a page where nothing moves, go back to the renderer to fix. In the paper boat example, the reviewer caught a faint flicker at the loop seam and sent it back for one round of fixes.

2D and 3D

2D mode makes an animated SVG or canvas page. 3D mode makes a Three.js scene. Both are a single HTML file you open in any browser.

Runs on Claude Code

The agents use your Claude Code subscription through the CLI. No API key, no extra billing setup.

Nothing is a black box

The brief, storyboard, design, keyframes, review notes and a preview screenshot are saved with every animation.

Install it in Claude Code

You need Node.js 18 or newer and Claude Code, signed in. Setup takes about two minutes.

  1. 1

    Download and build

    git clone https://github.com/ProProgramer123/claude-animation-studio.git
cd claude-animation-studio
npm install
npm run build
  2. 2

    Add it to Claude Code

    Run this from the same folder:

    claude mcp add animation-studio -- node "$(pwd)/dist/index.js"
  3. 3

    Turn on the browser check (recommended)

    This lets the studio open each animation in a headless browser, catch errors before the reviewer sees it, and save a preview image. Without it, the studio still works and skips the check.

    npx playwright install chromium
  4. 4

    Ask for an animation

    Start Claude Code and ask in plain words:

    Use the animation studio to make a 3D animation of a paper plane flying through clouds.

    Claude Code calls the create_animation tool for you. Finished animations are saved in an animations/ folder inside the folder you started Claude Code from.

    A full run takes a few minutes, since six agents work one after another. If Claude Code stops waiting, start it with a longer tool timeout, for example MCP_TOOL_TIMEOUT=900000 claude (15 minutes).

Settings

Pass these with claude mcp add, for example claude mcp add animation-studio -e ANIMATION_STUDIO_MODEL=sonnet -- node "$(pwd)/dist/index.js".

Environment variableDefaultWhat it does
ANIMATION_STUDIO_OUTPUT_DIRanimationsWhere finished animations are saved
ANIMATION_STUDIO_MODELyour Claude Code defaultModel the agents use, for example sonnet or opus
ANIMATION_STUDIO_RUNNERclaude-codemock returns canned replies for testing
ANIMATION_STUDIO_BROWSER_CHECKonoff skips the headless browser check
ANIMATION_STUDIO_CHROMIUM_PATHPlaywright's ChromiumUse a different Chrome or Chromium for the check
CLAUDE_CODE_PATHclaudePath to the Claude Code CLI if it isn't on your PATH
